# Akın Kökçü Portfolio

Akın Kökçü'nün siber güvenlik, ağ sistemleri, yönetim bilişim sistemleri ve açık kaynak geliştirme odağını bir araya getiren kişisel portföy projesidir.

This is the personal portfolio project of Akın Kökçü, bringing together cybersecurity, network systems, management information systems, and open-source development.

Canlı yayın / Live site: [naki667.github.io](https://naki667.github.io/)

## Proje Özeti / Overview

Bu portföy, sade bir statik yapı üzerine kurulmuştur ve içerik sunumunu ön planda tutar. Ana sayfada GitHub verilerinden beslenen etkileşimli proje-teknoloji ağı, hakkımda sayfasında eğitim ve yetkinlik odaklı içerik, projeler sayfasında seçili çalışmalar ve iletişim sayfasında sosyal bağlantılar ile Formspree tabanlı mesaj formu yer alır.

This portfolio is built on a simple static structure with a focus on clear content presentation. The home page includes an interactive project-technology network powered by GitHub data, the about page highlights education and technical background, the projects page presents selected work, and the contact page includes social links and a Formspree-based contact form.

## Öne Çıkan Özellikler / Key Features

- Çok sayfalı yapı / Multi-page structure: `index.html`, `about.html`, `projects.html`, `contact.html`
- Modern ve responsive arayüz / Modern and responsive interface
- GitHub API ile çalışan etkileşimli proje ve teknoloji ağı / Interactive project and technology network powered by the GitHub API
- Teknik yetkinlik ve sertifika sunumu / Technical skills and certificate presentation
- Formspree ile çalışan iletişim formu / Contact form powered by Formspree
- Erişilebilirlik paneli ve klavye dostu gezinme / Accessibility panel and keyboard-friendly navigation

## Yerel Olarak Çalıştırma / Run Locally

```bash
git clone https://github.com/NAKI667/akinkokcu.github.io.git
cd akinkokcu.github.io
```

Ardından `index.html` dosyasını modern bir tarayıcıda açabilirsiniz.

Then open `index.html` in a modern browser.
